# First generated readiness recovery campaign accepted

The Navigator accepted CV18.DS3's first bounded generated campaign over the
real production-default `HostService`. A Hypothesis state machine uses Petrus's
seeded authorities to combine one-step disclosed host progress, duplicate
webhook delivery, accepted-but-response-lost provider effects, abrupt runtime
generation reconstruction, fair convergence, and exact replay. The independent
readiness state is inspected at each generated boundary; successful runs admit
at most one readiness effect and one delivery observation before converging to
ready.

The campaign also proves checker sensitivity and counterexample custody. A
deliberate disposed-custody mismatch ends as a World-owned checker failure;
Hypothesis reduces the story; the exact terminal failed operation is retained
as a strict artifact; and replay reproduces the same failure through the one
interpreter. Primary failures cannot be replaced by teardown, close, cleanup,
retention, or replay diagnostics. Stale Timeline `pending` and one-step `step`
calls are fenced before they can reach a replacement generation.
