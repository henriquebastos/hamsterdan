# Typed acceptance expressed directly

RS-014 replaced six generic one-output Petri binding adapters with explicit
typed Petrus direct transformations. Human, change, repair, conversation,
dashboard, and readiness acceptance now expose their selected domain inputs and
single returned owner state in ordinary function signatures. Dynamic fan-out,
optional output, multi-owner folding, and target-sensitive routing remain
Petri-aware because those mechanics express genuine topology.

The strict Pydantic payload converter moved from host ownership to readiness
ownership, where it now serves both replayed Net transformations and
host-composed Activities. The exact Net remains 46 places, 69 transitions, and
309 arcs.

The production slice rejected an immediate Activity-bridge or universal
`owned_effect` helper: the narrow form obscured the existing fluent arcs, while
the universal form would restate exceptions as configuration. The independent
ES-002 branch continues exact-regeneration experiments with a small grammar of
named semantic fragment families. No DSL or Petrus change entered production.

Focused readiness conversion and Net tests passed 66 tests; host Activity and
application integration passed 74 tests. Quick and full gates passed, including
584 Python tests and 9 Amp webhook relay tests. Independent adversarial review
returned `APPROVE` with no required changes.
