canonical Activity results. The closed vocabulary contains only correlation,
repository/ref, patch admission, local Git operation, idempotency, current
authority, object write, exact CAS, and unavailable-boundary categories. It
cannot retain repository coordinates, refs, URLs, patches, model data, command

so an empty secondary patch cannot replace the first cause. Successful
publication runs schema/tree assertions and one replay; original, replay, and
cleanup evidence remain independent. Cleanup must be explicitly verified before
acceptance. Malformed booleans, unknown categories, repeated original evidence,
repeated assertions, and repeated cleanup evidence fail closed.

patch through production `HostGitPublisher`, advances exactly once, and proves
idempotent recovery without another ref mutation. Added tests cover original
stage retention, zero-publication suppression, secondary-error non-overwrite,
sanitation, stale-versus-unavailable final fences, local I/O normalization, and
separate replay/cleanup failures. Focused qualification, publisher, Activity,
Net, and Application suites pass 110 tests. The full gate passes 343 Python tests
with one explicit provider test skipped, nine Bun tests, formatting, Ruff, ty,
and source/wheel builds. No key, provider, subscription, paid/live operation,
remote repository action, AgentRunner change, or Petrus pin change occurred.
