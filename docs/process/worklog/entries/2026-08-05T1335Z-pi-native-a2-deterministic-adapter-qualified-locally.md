# Pi native A2 deterministic adapter qualified locally

Hamsterdan now maps its unchanged review, conversation, and coding contracts to
canonical bounded prompts and an injected public Petrus Pi operation lifecycle.
Host startup selects this adapter only after an exact `PI_NATIVE_A2_LOCAL` READY
probe and exact installation contract; missing, failed, non-ready, or A5 probes
leave a deterministic fail-closed runner and never select legacy Amp.

The adapter preserves strict request/result correlation, requires the durable
operation route before start, derives distinct deterministic runtime identities
for coding attempts under that same durable route, polls with stale-authority
and timeout cancellation, accepts only exact completed
settlement, and requires verified close. Canonical Petrus History still precedes
route settlement and startup repair reconstructs unresolved work. No connection
custody, supervision, Hands, Attachment, territory, Continuation, or effect
fencing implementation was copied.

Focused adapter and host suites passed 105 tests. `scripts/check full` passed
formatting, Ruff, ty, nine Bun relay tests, source and wheel builds, and 285
Python tests; the one explicitly opt-in provider test remained skipped. No
authority was consulted, no real provider operation was started, and no paid or
live work ran.

Production remains fail-closed until Petrus exposes a supported A2 host factory
that owns authority-capable topology assembly and teardown. A subsequent
deterministic slice should consume that surface before a separately authorized
live gate.
