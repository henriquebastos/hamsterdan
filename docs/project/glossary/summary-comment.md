# Summary Comment

The one PR comment the app keeps editing in place, showing where every requirement stands right now. It is reposted only when its content actually changes.

- Use when: the live status comment that gets edited, never re-posted.
- Do not use for: the ready comment, which is a once-per-generation verdict.
- Avoid: dashboard, status board.
- Related: [Ready Comment](ready-comment.md), [Requirement](requirement.md)
