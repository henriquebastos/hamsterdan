# Notebook

The single record where one part of the PR workflow keeps everything it remembers about this pull request, built up fact by fact, never by re-reading the PR. Exactly one copy exists: it travels inside any outside call the part makes, so a second call cannot start until the notebook is back. Each entry is stamped with the generation it belongs to.

Avoid: baton, memory, state (for this record), snap, snapshot (for this record), ladder, projection
