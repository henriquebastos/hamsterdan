# Ready Comment

The single PR comment posted when a pull request flips from not-ready to ready, stating that every requirement is met and that humans keep merge authority. Posted at most once per generation; the app never merges.

- Use when: the once-per-generation verdict comment.
- Do not use for: the summary comment, which is edited in place as things change.
- Avoid: advisory, readiness advisory, announce.
- Related: [Requirement](requirement.md), [Summary Comment](summary-comment.md), [Generation](generation.md)
