# Requirement

One condition a pull request must meet before the ready comment is posted: checks pass, review findings resolved, approvals present, no unresolved threads, base branch current.

- Use when: one condition in the readiness verdict.
- Do not use for: the local test suite (the full check) or GitHub-side permission checks.
- Avoid: gate, when speaking of conditions; gate fact.
- Related: [Ready Comment](ready-comment.md), [Summary Comment](summary-comment.md)
