# CV2.DS2 — Conversational guarded change

## Intent

Prove the complete natural conversation-to-code path with Petrus's current Amp
agent strategy inside the operational orb. The conversation agent selects one
typed host intent, the coding agent edits a disposable credential-free checkout,
and only the host may publish the captured diff through GitHub App authority.

## Acceptance behavior

Given a fresh same-repository demo PR at an exact admitted generation
When a trusted human naturally requests one bounded source change through the
configured App mention
Then Hamsterdan stages the exact request and publishes confirmation guidance
without invoking the coding agent or mutating GitHub.

Given that pending request
When a second mention exactly confirms its host-generated kind and digest
Then the coding agent runs in a disposable checkout at the pending head
And receives no GitHub credential
And the host captures and validates the actual changed paths and diff
And the App publishes one operation-identified commit by exact ref comparison
And the resulting head enters a fresh readiness generation.

Given an altered digest, arguments, head, base, policy, duplicate delivery,
agent inability, malformed output, or uncertain provider result
When authorization or recovery runs
Then no unintended commit or duplicate comment is created
And stale work cannot supersede current authority
And recoverable state remains visible in the durable dashboard and History.

## Live evidence route

Create a fresh controlled `first-attempt-flake` PR. After it reaches ready,
request a precise conversational change that retains a unique scenario label
but changes behavior to deterministic pass. Confirm only through the exact
mention guidance. Verify conversation, coding, coordinating-review, Actions,
App commit attribution, operation trailers, new-head admission, dashboard,
restart, and duplicate-delivery behavior without merging the PR.

## Accepted evidence

PR 15 staged a natural bounded change without invoking coding, rejected an
altered confirmation digest without mutation, and accepted the exact digest.
The credential-free Amp coding agent changed only `.pr-lab/scenario.json`, and
the host published App-authored commit
`b90680615675721a4247131473b512a782b273e5` with operation and payload trailers.
The PR advanced from epoch 1 to epoch 2, brokered its expected first-attempt CI
flake to successful attempt 2, completed coordinating review with no findings,
and returned to a current ready dashboard. Inbox custody ended with 221
terminal deliveries, no pending delivery, and no failure. No duplicate,
self-loop, credential-bearing log, manual push, approval, or merge occurred.

Qualification also exposed and corrected three production defects before
acceptance: provider-backed 50 ms agent polling, non-recovering review
inability, and case-sensitive comparison of canonical GitHub repository names.
Agent coding retries are bounded to three identical, freshly fenced attempts.

## Out of scope

- Separate hostile-code OS isolation.
- Petrus, AgentRunner, Motus Dispatch, or execution-environment redesign.
- Merge, force-push, protection bypass, or agent-held GitHub credentials.
- Stale-base and conflict-resolution live scenarios, which belong to CV3.
