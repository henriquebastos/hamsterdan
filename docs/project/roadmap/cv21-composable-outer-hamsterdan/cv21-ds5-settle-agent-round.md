# CV21.DS5 — Settle one reconstructible agent round

## Outcome

Execute one real retained-workflow review or conversation request through the
new credential-free agent protocol, host-owned route/runtime custody, bounded Pi
execution, and exact readiness result delivery. The round remains recoverable
across submission, execution terminal, cancellation, receiver delivery, and
workflow terminal cuts.

## Vertical path

```text
retained agent work -> bridge typed work -> readiness authority/request custody
  -> host route -> credential-free Pi/workspace -> exact retained result
  -> readiness delivery -> bridge strict terminal -> original occurrence
```

## Owns

- agent request/result/terminal protocol, Pi adaptation, and workspace safety;
- host operation-to-route binding, runtime/secret lifetime, cancellation, and
  erasure evidence;
- readiness request/attempt custody, exact receiver delivery, first complete
  protected-work authority claim, and findings fence; and
- review/conversation bridge families and deterministic correspondence.

## Excludes

No mutation publication, GitHub credentials in agent territory, complete later
lifecycle matrix, new review/conversation workflow fold, or inferred result from
logs.

## Acceptance

- submission, execution terminal, and receiver delivery are distinct durable
  identities and cuts;
- phase/incarnation/head/base/policy agree across durable grant, fresh provider
  truth, and fresh host evidence at the first protected call;
- cancellation and stale authority fail closed without fabricating a workflow
  terminal;
- retained exact results are delivered after reconstruction before new work;
  and
- secrets never enter commands, artifacts, state, diagnostics, or agent input.
