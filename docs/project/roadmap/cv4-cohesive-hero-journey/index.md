with a human author, a distinct team reviewer, and Hamsterdan acting visibly as
the App. The journey should demonstrate the largest compatible set of review,
repair, conversation, collaboration, dashboard, and readiness behaviors on one
fresh PR without faking provider state.

  GitHub authority state.
- The host owns every App effect and exact-head fence.
- Human credentials remain explicit operator sessions outside agent territory.
- Native review fallback must fail closed for authorization and malformed
  payloads.
- The rehearsal PR remains isolated and unmerged.
